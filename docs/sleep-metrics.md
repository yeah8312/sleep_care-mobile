# Sleep Metrics And Recommendation Formulas

이 문서는 `Sleep Care` 앱이 2026년 6월 10일 기준으로 사용하는 수면 분석 및 추천 계산식을 정리한다.

## 1. 원본 수면 세션 처리

원본 데이터는 Health Connect `SleepSessionRecord`에서 읽는다.

- 기본 세션 시간: `endTime - startTime`
- 밤중 각성 시간: stage 중 `AWAKE`, `AWAKE_IN_BED`, `OUT_OF_BED` 합
- 수면 stage 시간: stage 중 `LIGHT`, `DEEP`, `REM`, `SLEEPING` 합

### 분할 밤잠 병합

주간 분석과 홈 대시보드 집계 전에는 인접한 수면 세션을 먼저 병합한다.

- 공백이 `3시간 이하`
- 두 세션 중 하나라도 야간 수면 성격
  - 자정 넘김
  - 시작 시각이 `18:00` 이후
  - 종료 시각이 `10:00` 이전

병합 시:

- 시작 시각: 첫 세션 시작
- 종료 시각: 마지막 세션 종료
- 총 수면 시간: 전체 구간 길이
- 밤중 각성 시간: 두 세션의 각성 시간 + 중간 공백

## 2. 수면일(Sleep Day) 집계

주간 수면 리듬과 분석 점수는 세션 그대로 쓰지 않고 `기상한 날짜` 기준으로 묶는다.

- 예: 토요일 밤에 자서 일요일 아침에 일어나면 `일요일 수면일`

수면일마다:

- `primarySession`: 대표 야간 수면 1개
- `totalMinutes`: 해당 날짜로 귀속된 전체 수면 시간
- `extraSleepMinutes`: `totalMinutes - primarySession.totalMinutes`

`extraSleepMinutes`는 낮잠 또는 분할 수면 후반부를 포괄하는 보조 지표다. UI에서는 `추가 수면`으로만 표시하고, 낮잠이라고 단정하지 않는다.

## 3. 규칙성 점수

수면 분석 화면의 `규칙성`은 더 이상 sleep stage 비율이 아니라 `취침/기상 시각 일관성`이다.

### 취침 시각 정규화

취침 시각은 야간 축 기준으로 비교하기 위해 자정 이후 값을 다음 날로 넘긴다.

- `00:30` -> `24:30`
- `02:10` -> `26:10`

### 기상 시각 정규화

기상 시각은 일반적인 오전 기상 패턴 기준으로 그대로 사용한다.

### 점수 계산

최근 7일 대표 수면에 대해:

1. 평균 취침 시각 계산
2. 평균 기상 시각 계산
3. 각 날짜의 취침 시각과 평균 취침 시각 차이의 절대값 평균 계산
4. 각 날짜의 기상 시각과 평균 기상 시각 차이의 절대값 평균 계산

패널티:

- 취침 패널티: `평균 취침 편차(분) / 5`, 최대 25점
- 기상 패널티: `평균 기상 편차(분) / 4`, 최대 30점

최종 점수:

```text
regularityScore = 100 - bedtimePenalty - wakePenalty
regularityScore는 35~100으로 제한
```

수면일이 1개뿐이면 규칙성은 임시로 `85점`을 사용한다.

## 4. 최근 7일 수면 점수

수면 분석 화면의 상단 `최근 7일 수면 점수`는 다음 주간 평균값으로 계산한다.

- `averageMinutes`: 최근 7일 수면일의 `totalMinutes` 평균
- `regularityScore`: 위 규칙성 점수
- `awakeMinutes`: 최근 7일 대표 수면의 밤중 각성 시간 평균

최종 식:

```text
durationScore = totalMinutes / 4.8, 최대 40점
consistencyPart = regularityScore * 0.35, 최대 35점
awakePenalty = awakeMinutes, 최대 10점

weeklySleepScore = durationScore + consistencyPart + 25 - awakePenalty
weeklySleepScore는 35~100으로 제한
```

분석 화면에서는 `latencyMinutes`를 사용하지 않는다.

## 5. 홈의 어제 수면 상태

홈의 `어제 수면 상태`는 가장 최근 수면일 기준으로 계산한다.

- 총 수면 시간: 그 수면일의 `totalMinutes`
- 점수: 위 하루 수면 블록에 대해 `ScoreCalculator.sleepQuality()` 재계산
- 규칙성 입력값: 해당 대표 수면의 기존 세션 점수 사용

즉 홈은 최신 하루 중심, 분석 화면은 최근 7일 중심이다.

## 6. 추천 입력과 상태

수면 스케줄 추천은 데모 기본값을 만들지 않고 실제 저장된 입력만 사용한다.

- Health Connect 수면 세션
- 최근 14일 Pi 졸음 이벤트
- 사용자가 직접 저장한 목표 기상 시각과 선호 취침 시각
- 사용자가 직접 저장한 학습 가능 시간대
- 앞으로 14일 안의 시험 일정

추천 결과 상태:

- `NeedsSetup`: 수면 목표, 학습 플랜, 수면 기록, 예정 시험이 모두 없어서 개인화 기준이 없는 상태
- `LowConfidence`: 추천은 가능하지만 수면 세션이 3개 미만이라 리듬 판단을 보류한 상태
- `Ready`: 수면 리듬 판단까지 포함해 계산한 상태

## 7. 추천용 수면 리듬 판단

추천 엔진은 최근 수면 세션 최대 7개를 사용한다.

- 취침 시각 중앙값
- 기상 시각 중앙값
- 평균 수면 시간
- 취침/기상 시각의 평균 절대 편차

취침 시각은 자정 이후 값을 다음 날 축으로 넘겨 비교한다.

- `00:30` -> `24:30`
- `02:10` -> `26:10`

리듬 모드:

- `Stable`: 수면 세션이 3개 이상이고 취침/기상 편차의 최댓값이 `45분 이하`
- `Drifting`: 편차 최댓값이 `46~90분`
- `Irregular`: 편차 최댓값이 `90분 초과`
- `InsufficientData`: 수면 세션이 3개 미만

리듬이 흔들릴 때는 목표 취침/기상으로 한 번에 이동하지 않는다.

- `Stable`, `InsufficientData`: 목표 시간을 그대로 사용
- `Drifting`: 취침/기상 모두 하루 최대 `30분` 이동
- `Irregular`: 취침은 하루 최대 `30분`, 기상은 하루 최대 `45분` 이동

단, 3일 이내 오전 시험의 기상 마감은 지각 방지를 위해 이동 제한을 적용하지 않는다.

## 8. 목표 수면 시간

기본 목표 수면 시간은 `450분`이다.

보정 규칙:

- 최근 평균 수면이 `390분 미만`: `+30분`
- 최근 평균 수면이 `390분 이상 420분 미만`: `+15분`
- 리듬 모드가 `Irregular`: `+15분`
- 최근 14일 졸음 패턴 보정: `+0~30분`
- 3일 이내 시험이 있으면 최소 `480분`

최종 목표 수면 시간은 `420~540분`으로 제한한다.

## 9. 졸음 패턴 반영

졸음 이벤트는 추천 시점 기준 최근 14일만 사용한다. 14일 밖 이벤트는 추천 사유, 팁, 판단 근거에 반영하지 않는다.

시간대 버킷:

- 새벽: `00:00~05:59`
- 오전: `06:00~11:59`
- 오후: `12:00~17:59`
- 밤: `18:00~23:59`

반복 강도:

- 같은 시간대 피크가 `3회 이상`: `NeedsAction`
- 최근 14일 전체 이벤트가 `3회 이상`: `Watch`
- 그 외 이벤트 있음: `Good`
- 이벤트 없음: `Unknown`

졸음 이벤트가 없으면 "졸음 패턴" 대신 `Pi 이벤트`로 표시하고, 추천 문구에서는 졸음을 원인처럼 언급하지 않는다.

## 10. 시험 일정 반영

추천 엔진은 오늘 이후 14일 안의 가장 가까운 시험 1개를 본다. 오늘 시험이라도 이미 시작 시간이 지난 항목은 제외한다.

시험 시간대:

- `EarlyMorning`: `00:00~09:59`, 기상 마감은 시험 시작 `120분 전`
- `LateMorning`: `10:00~11:59`, 기상 마감은 시험 시작 `90분 전`
- `Afternoon`: `12:00~17:59`, 기상 마감 없음
- `Evening`: `18:00~23:59`, 기상 마감 없음

오전 시험은 사용자의 일반 기상 기준이 기상 마감보다 늦을 때만 기상 시간을 앞당긴다. 오후/저녁 시험은 기상 시간을 앞당기지 않고 시험 전 복습 블록으로만 반영한다.

## 11. 권장 취침/기상 시각

일반 기상 기준:

1. 사용자가 설정한 목표 기상 시각
2. 최근 수면 세션의 기상 중앙값
3. 기본값 `06:30`

선호 취침 시각만 있고 목표 기상 시각과 수면 중앙값이 없으면, `선호 취침 + 목표 수면 시간 + 15분`을 기상 기준으로 사용한다.

권장 취침 시각:

```text
recommendedBedtime = recommendedWakeTime - targetSleepMinutes - 15분
```

추천 결과에는 시간만 저장하지 않고 다음 정보를 함께 저장한다.

- 판단 근거: 수면 시간, 리듬 조정, Pi 이벤트/졸음 패턴, 시험 일정, 학습 가능 시간, 사용자 목표
- 행동 블록: 취침 준비, 첫 집중 블록, 회복 블록, 시험 전 준비 블록
- 팁: 현재 입력이 부족하면 설정/연동 안내를 우선 표시
