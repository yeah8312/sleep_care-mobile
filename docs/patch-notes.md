# 패치노트

## 2026-06-10 수면 스케줄 제안 개선

### 주요 변경

- 수면 스케줄 제안이 데모 시드 데이터 대신 실제 입력 데이터만 사용하도록 변경했습니다.
- 초기 상태에서는 학습 플랜과 시험 일정이 자동 생성되지 않으며, 추천 화면은 `기준 설정 필요` 상태를 보여 줍니다.
- 사용자가 목표 기상 시각과 선호 취침 시각을 직접 저장할 수 있는 수면 목표 입력 UI를 추가했습니다.
- 학습 플랜은 `학습 가능 시작`, `학습 가능 종료`, `공부 요일`, `자동 회복 블록 사용`만 남겨 추천 루틴의 입력값으로 단순화했습니다.
- 학습 플랜 저장이 사용자 목표 기상 시각을 자동으로 덮어쓰던 동작을 제거했습니다.
- 시험 일정 카드에 수정 버튼을 추가하고, 수정 시 기존 일정이 같은 ID로 업데이트되도록 했습니다.
- 시험 일정 저장 시 날짜와 시작/종료 시간의 형식을 검증하고, 종료 시간이 시작 시간보다 늦지 않으면 저장하지 않습니다.
- 오전 시험은 필요한 경우 기상 마감 시각으로 반영하고, 오후/저녁 시험은 기상 시간을 앞당기지 않고 복습/회복 블록으로 반영합니다.
- 최근 14일 졸음 이벤트만 추천 판단에 사용하며, 졸음 이벤트가 없으면 졸음을 근거처럼 말하지 않도록 정리했습니다.
- 추천 결과에 판단 근거와 오늘 실행할 행동 블록을 추가했습니다.
- 추천 스냅샷 저장 구조를 JSON 기반 필드로 확장하고 Room DB 3 -> 4 마이그레이션을 추가했습니다.

### 사용자 경험

- 추천 화면에서 권장 취침/기상 시간뿐 아니라 `판단 근거`와 `오늘 실행 블록`을 함께 확인할 수 있습니다.
- 데이터가 부족한 경우 추정값을 강하게 말하지 않고, 어떤 입력이 없는지 명확히 표시합니다.
- 현재 수면 리듬과 목표 시간이 크게 다르면 한 번에 목표 취침으로 이동하지 않고 오늘 이동 가능한 폭으로 제안합니다.
- 오후 시험이 있어도 불필요하게 90분 일찍 일어나도록 강제하지 않습니다.

### 검증

- `.\gradlew.bat testDebugUnitTest` 통과
- Android 에뮬레이터 `Medium_Phone_API_36.1`에서 초기 상태, 수면 목표 저장, 학습 가능 시간 저장, 시험 추가/수정, 오후 시험 추천 블록을 확인했습니다.
- 에뮬레이터 crash 로그와 앱 프로세스 로그에서 기능 관련 FATAL/Exception은 확인되지 않았습니다.
