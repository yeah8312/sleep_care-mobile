# 데이터 및 추천 계획

## 현재 구현 상태
- 모바일 앱은 라즈베리파이에서 오는 `risk.update`, `alert.fire`, `session.summary`를 기준으로 세션과 졸음 이벤트를 저장한다.
- 모바일 앱은 워치 심박 배치와 ACK 커서 구조를 반영하는 중이며, 심박/IBI 데이터는 세션 해석 보조 지표로 사용한다.
- 실제 수면 세션은 Health Connect 기반으로 연결되었고, 수면 분석은 최근 7일 수면일 집계를 사용한다.
- 추천 엔진은 데모 시드 없이 실제 입력된 `수면 기록 + 최근 14일 Pi 이벤트 + 시험 일정 + 학습 가능 시간 + 사용자 목표`만 사용한다.
- 추천 화면은 개인화 기준이 없으면 `NeedsSetup` 상태로 표시하고, 충분하지 않은 데이터는 추정하지 않고 판단 근거 카드에서 명시한다.

## 핵심 데이터
### 학습 세션 데이터
- 세션 ID
- 시작/종료 시각
- 세션 상태
- 마지막 위험 상태
- 누적 알림 수
- 세션 요약 정보

### 졸음 이벤트 데이터
- 발생 시각
- 감지 강도 또는 신뢰도
- 지속 시간
- 감지 당시 상태 정보
- 기기 ID
- 세션 ID

### 심박 데이터
- 샘플 시각
- BPM
- IBI
- 품질 라벨
- 전달 모드
- ACK 커서
- 백필 요청 기준
- 모바일 앱은 심박 샘플 큐와 커서를 저장하고 `hr.ingest` 로 Pi에 중계한다.

### 수면 데이터
- 수면 시작 시각
- 수면 종료 시각
- 총 수면 시간
- 수면 품질 관련 지표
- 동기화 시각
- 주간 분석용 수면일 집계
- 추가 수면 시간
- 현재 구현에서는 Health Connect 권한/가용성/실제 기록 여부에 따라 비어 있을 수 있다.

### 사용자 입력 데이터
- 학습 플랜: 학습 가능 시작/종료, 공부 요일, 자동 회복 블록 사용 여부
- 시험 일정: 이름, 날짜, 시작/종료, 장소, 우선순위, 캘린더 동기화 여부
- 사용자 목표: 목표 기상 시간, 선호 취침 시간

## 분석 결과 데이터
- 일별 졸음 빈도
- 주간 수면 규칙성
- 수면 부족 가능성 지표
- 권장 취침 및 기상 시간
- 시험 대비 수면 조정 가이드

### 현재 수면 지표 의미
- 최근 7일 수면 점수: 최근 7일 수면일의 평균 수면 시간, 취침/기상 시각 일관성, 밤중 각성 평균을 조합해 계산
- 규칙성: sleep stage 비율이 아니라 취침/기상 시각 평균 편차 기반 점수
- 주간 수면 리듬: `기상한 날짜` 기준 대표 수면 1개와 추가 수면 요약
- 분할 밤잠 보정: `3시간 이하 공백`의 인접 야간 세션은 하나로 병합

## 초기 추천 로직 방향
- 규칙 기반 분석 우선
- 데모 학습 플랜/시험 일정은 생성하지 않음
- 최근 수면 평균으로 목표 수면량 계산
- 취침/기상 일관성은 점수가 아니라 `Stable`, `Drifting`, `Irregular`, `InsufficientData` 모드로 판단
- 수면 데이터가 부족하면 수면 리듬 판단을 보류하고 `LowConfidence` 또는 `NeedsSetup` 상태를 표시
- 최근 14일 Pi 이벤트가 있을 때만 졸음 패턴을 추천 사유와 회복 블록에 반영
- 시험 일정과 학습 가능 시간대를 고려한 오늘 실행 블록 제안
- 실시간 심박 데이터는 장기 추천의 주 지표보다 세션 해석 보조 지표로 사용
- 수면 데이터가 없을 때는 "수면 기록 기반 보정 없음" 설명을 함께 제공
- 권장 기상은 `사용자 목표 기상 -> 최근 수면 기상 중앙값 -> 기본 06:30`을 기준으로 삼고, 오전 시험의 기상 마감만 필요한 경우에 반영한다.
- 오후/저녁 시험은 기상 시간을 앞당기지 않고 시험 전 복습/휴식 블록으로 반영한다.
- 권장 취침은 `권장 기상 - 목표 수면 시간 - 15분 준비 시간`으로 계산한다.

## 처리 구조 기준
- Repository 계층에서 라즈베리파이 졸음 데이터, 학습 세션 데이터, 수면 데이터, 사용자 입력 데이터를 통합한다.
- ViewModel + Coroutines + Flow 조합으로 조회 상태와 추천 결과 상태를 화면에 전달한다.
- 현재 핵심 반영은 실시간 Flow 중심이며, 수면 동기화 워커는 비활성 상태다.
- 추천 결과는 캐시해 홈 화면과 상세 화면에서 같은 결과를 재사용할 수 있게 한다.
- 추천 캐시는 Room v4부터 `status`, `factorsJson`, `actionBlocksJson`을 저장한다. 기존 `tips` 문자열은 JSON 우선으로 읽되, 이전 구분자 형식도 읽을 수 있게 유지한다.
- 세부 계산식과 정규화 규칙은 [sleep-metrics.md](./sleep-metrics.md)를 기준으로 유지한다.

## 추천 예시
- 최근 수면 평균이 부족하면 목표 수면 시간을 늘리고, 취침 준비 블록을 앞당긴다.
- 취침/기상 편차가 크면 목표 시간으로 한 번에 이동하지 않고 오늘 이동 가능한 폭만 제안한다.
- 오전 시험은 사용자의 일반 기상 기준이 늦을 때만 기상 마감을 반영한다.
- 오후/저녁 시험은 기상 시간을 앞당기지 않고 시험 3시간 전 복습 블록과 1시간 전 정리 시간을 제안한다.
- 최근 14일 Pi 이벤트가 없으면 추천 이유와 팁에서 졸음을 원인처럼 언급하지 않는다.
